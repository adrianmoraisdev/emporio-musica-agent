# Empório da Música — Agente de Atendimento

Protótipo de agente de atendimento por mensagens de texto para a **Empório da Música**,
loja fictícia de instrumentos musicais em Campo Grande/MS (desafio técnico AI Engineer).

> 🚧 Em construção. Este README será completado ao longo do desenvolvimento.

## Estrutura

```
data/                 # CSVs operacionais + manual de políticas (PDF) fornecidos pela loja
src/emporio_agent/    # código do agente
tests/                # testes automatizados
```

## Como rodar

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -e ".[dev]"
pytest
```
